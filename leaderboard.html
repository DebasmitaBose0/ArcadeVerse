ALGORITHMIC EVALUATION

How Application Intelligence Calculates Your Arcade Points

The client-side engine queries live GitHub activity and audits repository assets to calculate scores transparently:

01

Live GitHub REST Ingestion

Directly queries /repos/DebasmitaBose0/ArcadeVerse/contributors to fetch merged commits, pull requests, and author handles in real time.

02

Isolated Directory Audit

Cross-references registered games in the 'games' folder to verify complete playable code, zero git merge conflicts, and vanilla architecture.

03

Mechanics & Bonus Multipliers

Audits advanced Canvas physics, AI opponents, audio FX, particle systems, and platform features to calculate verified bonus scores.

04

Automated Badge Synthesis

Evaluates cumulative score and automatically unlocks highest badges across both Games Dedicated and Milestones categories simultaneously.
