Favorites Architecture & Persistence

The favorites system uses a high-performance, single-source-of-truth manager backed by HTML5 localStorage:

  • Namespaced Key: arcadeverse:preferences:favorites stores an array of unique game IDs.
  • Backward Compatibility: Keeps the legacy key arcadeverse_favorite_games in sync so existing platform utilities function smoothly.
  • DOM Event Safety: Favorite toggle clicks call e.stopPropagation() to prevent unintended game modal launches.
  • Real-Time Sync: Listens to the window.storage event to instantly synchronize bookmark states across multiple browser tabs.
